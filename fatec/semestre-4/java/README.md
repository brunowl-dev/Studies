# Java — Semestre 4

Cada pasta é um exercício ou mini-projeto de POO em Java, feito no Eclipse. Alguns destaques:

- `sistemalocacao`-style projects (`abstratainterface`, `classesabstratas`, `polimorfismo`, `heranca`, `encapsulamento-1/2`) — exercícios focados em cada pilar da POO
- `feira`, `oficinamecanica`, `papelaria`, `organiza-cidade`, `cinemas` — pequenos sistemas temáticos usados para praticar modelagem de classes
- `aula1` a `aula5`, `aula52` — exercícios acompanhando as aulas
- `figurasgeometricas` — cálculo de áreas com herança/polimorfismo
- `correcaop1`, `exercicios1` — correções e exercícios avulsos
