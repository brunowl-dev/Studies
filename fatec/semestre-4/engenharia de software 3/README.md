# ⚙️ Engenharia de Software 3

Atividades feitas na disciplina de Engenharia de Software 3, na Fatec Baixada Santista.

> ℹ️ **Contexto importante:** a maior parte dessas atividades partiu de uma estrutura de código e/ou instruções já fornecidas pelo professor (repositório-base, pipeline pré-configurado, etc.). O trabalho realizado foi complementar — implementar o que era solicitado em cima dessa base, seguindo as instruções descritas em cada atividade. Deixo isso claro para que o conteúdo seja avaliado no contexto correto: aprendizado guiado, não projetos autorais.

## 📂 Atividades

| Pasta | Tema | O que foi feito |
|---|---|---|
| [`roteiro-ci-cd/`](./roteiro-ci-cd) | Introdução a CI/CD | Atividade introdutória com pipeline pré-preparado pelo professor; commits e deploys realizados como prática do fluxo |
| [`teste-automatizado-playwright/`](./teste-automatizado-playwright) | Testes automatizados (Playwright) | Escrita de testes end-to-end seguindo o roteiro da disciplina |
| [`teste-unitario-junit/`](./teste-unitario-junit) | Testes unitários (JUnit) | Complementação de testes unitários em cima de uma base de código fornecida |
| [`event-driven/`](./event-driven) | Arquitetura orientada a eventos | Atividade prática sobre event-driven architecture, a partir de instruções e repositório-base do professor |

## 🎯 O que essas atividades demonstram

Mesmo sendo guiadas, essas atividades cobriram conceitos importantes de engenharia de software: integração e entrega contínua (CI/CD), testes automatizados de ponta a ponta, testes unitários e arquitetura orientada a eventos — temas que fazem parte do dia a dia de um desenvolvedor profissional.
