# 🎨 Frontend

Exercícios e projetos práticos de HTML, CSS e JavaScript, feitos majoritariamente seguindo o roteiro de estudos do [roadmap.sh](https://roadmap.sh/frontend).

## 📂 Estrutura

Cada tecnologia tem sua própria pasta, e dentro dela, **cada projeto vive em sua própria subpasta** — assim cada um pode ter seus próprios arquivos extras (imagens, estilos, scripts) sem se misturar com os outros.
