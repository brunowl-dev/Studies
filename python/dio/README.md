# DIO — Digital Innovation One

Projetos práticos feitos durante trilhas/bootcamps da DIO: sistema bancário (com versões incrementais), calculadora de descontos, organizador de eventos, sistema de reservas de hotel, organização hospitalar, simulador de carrinho de compras, validação de e-mail e exercícios de TAD (Tipo Abstrato de Dados) para controle de estoque e gerenciamento de tarefas.
